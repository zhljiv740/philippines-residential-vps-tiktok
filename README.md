这点差价买的是 IP 属性。家宽款给的是双 ISP 家庭住宅 IPv4，同一台机器挂两个运营商出口，数据库里识别成家庭宽带。专线款是菲律宾原生 IP，归属地没问题，但不带住宅属性。

这个区别在什么场景下有意义：TikTok 判断环境真不真，看的是 IP 的 ISP 类型和风险分，机房段和住宅段在系统里的待遇不同。批量注册、多个账号在同一环境下切换、需要长期养号的矩阵，IP 属性直接影响存活率。反过来，只是给一个已成熟的账号发视频、传素材、看后台数据，专线款的 IP 够用。

- 起号、养号、多账号运营 → 家宽款
- 单账号发布、内容搬运、只要求 IP 归属菲律宾 → 专线款

## 三网实测：移动能直连，电信不配中转就是白买

先给结论：移动最好，联通次之，电信最差且必须中转。两份独立的第三方测速记录在这一点上完全一致，只有具体数字有出入。

**中国移动**：一份三网回程测试给的平均值是 183ms，最快 79ms（广州节点）；另一份记录约 90ms，回程走 CMI 直连。两个数字口径不同，一个是全网平均，一个是较优节点，看趋势就好。去程走香港直连菲律宾，是三条路里最干净的。

**中国联通**：平均 206ms，最快 113ms；另一份记录约 230ms。去程经日本转菲律宾，绕了一点但可接受。

**中国电信**：平均 357ms，最快 240ms，最慢 395ms；另有记录 380ms 以上。去程要先绕美国、再经新加坡才到菲律宾，这条路径决定了延迟下不来。

国际方向的延迟数据：到菲律宾本地 24ms，亚洲平均 86ms，北美 196ms，欧洲 227ms。也就是说机器本身出口没问题，问题全在国内这一段怎么过去。

带宽实测能跑满 50Mbps 下行，上行稳定在 35Mbps 以上，亚太方向最高测到 47Mbps。发视频、传素材够用，2 人同时推流理论上也撑得住，但延迟高的线路推流会卡在握手和缓冲上。

如果你是电信宽带又不想折腾中转，这台机器不适合你，钱花下去体验也不会好。官方在商品页明确提示“直播建议中转”，这不是别人加的注解。移动用户可以直接下单，联通用户能接受 200ms 出头的延迟也没问题。

## 原生加家宽到底意味着什么，以及那个 75 分是怎么回事

原生 IP 指这段地址最初就在菲律宾注册分配，不是从别处广播过来的，TikTok 的地区识别会稳定显示菲律宾。家宽属性指 IP 在数据库里的 ISP 类型是家庭宽带，而不是数据中心。双 ISP 指同一台机器有两个运营商出口，单条线路抖动时不至于整体掉线。

第三方工具的实际检测结果比官方描述复杂一些：IP 数据库判定为原生 IP，属性栏混合了“机房/商业/家宽”三种标签；大部分风险评分显示极低或低；但 IPQS 给了 75 分，标注为可疑 IP。代理和 VPN 检测里，多个数据库判定为非代理、非 Tor，少数显示为 VPN，这在 VPS 产品里属于常见情况。

所以别把它当成“零风控 IP”来理解。它是一个归属地正确、带住宅属性、但在部分风控库里会被打上问号的地址。实际使用中第三方测试没有触发 TikTok 风控，账号状态正常，但这属于个案观察，不构成对所有人所有账号的保证。

解锁方面，IPv4 环境下 TikTok、Netflix（菲律宾区内容）、YouTube、Amazon Prime Video、Spotify、ChatGPT 全部通过。IPv6 是广播地址，解锁能力明显弱于 IPv4，需要解锁能力时优先走 IPv4。

## 哪些人不用买这一款

**电信宽带且不打算配中转的**。上面已经说过，去程绕美国再绕新加坡，延迟 350ms 起，发视频和直播都会难受。

**要在 VPS 上跑安卓模拟器的**。512MB 内存跑 TikTok 后台够用，跑模拟器不够，会直接卡死。需要模拟器就去看配置更高的方案。

**想拿它建站或跑重业务的**。1 核 512MB、50Mbps 限速端口、1TB 双向流量，这组参数是给账号运营设计的，不是给网站和下载业务设计的。

**对直播延迟极度敏感又不接受中转的**。官方对菲律宾节点的建议就是直播加中转，纯直连的稳定性不够。

## 常见问题

**这台的 1TB 是单向还是双向？**

双向，上传和下载都计入。发视频主要消耗上传，1TB 双向对单账号日常发布够用，多账号批量上传要算一下。另外有第三方评测把这款的月流量记为 1.5TB，与官方标注的 1TB 不一致，下单前以商品页当前显示为准。

**超了流量会停机吗？**

不会。超出后限速到 5Mbps，机器继续运行，下个月恢复。5Mbps 发文字和图片没问题，传视频会明显变慢。

**能用来做 TikTok 直播吗？**

能推流，但官方建议配中转。50Mbps 带宽支持约 2 人同时推流，瓶颈在国内到菲律宾这一段延迟，不在带宽。移动用户直连直播的体验会好于电信联通。

**优惠码在哪里填？**

结账页面有独立的优惠码输入框，填完点应用再核对总价。如果金额没变，先确认你买的套餐是否在排除名单里（台湾、新加坡、美国家宽系列部分套餐）。

**账户用什么币种结算？**

可以设成 AUD，支持支付宝、信用卡（Stripe）、微信扫码和 PayPal。人民币价格是按汇率折算的展示值，实际扣款以澳元为准。
